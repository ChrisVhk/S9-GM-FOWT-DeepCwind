This directory stores a numeric array in an open and simple format that is
universally readable (Darr, see: https://pypi.org/project/darr/). It is
easiest to read the array data using the code provided below for a number of
popular analysis environments. If your language is not included, the data
format description specifies all information needed to read the data.

Data format description
=======================

The file '04 arrayvalues_pdfWoB.bin' contains the raw binary values of the numeric
array, without header information, in the following format:

  Numeric type: 64-bit IEEE double precision float (sign bit, 11 bits exponent, 52 bits mantissa)
  Byte order: little (most-significant byte last)
  Array dimensions: (18, 7, 9, 6)
  Array order layout:  C (Row-major; last dimension varies most rapidly with memory address)

This information is also stored in JSON format in the separate UTF-8 text
file, '04 arraydescription_pdfWoB.json'.

Code for reading the numeric data
=================================

Note that the array is 4-dimensional and stored with a row-major memory
layout. In column-major languages (see Note below), the code provided here
will lead to an array that has its dimensions reversed (6, 9, 7, 18) with
respect to the format description above (18, 7, 9, 6).

Python with Darr:
-----------------
import darr
# path_to_data_dir is the directory that contains this README
a = darr.Array(path='path_to_data_dir')

Python with Numpy:
------------------
import numpy as np
a = np.fromfile('04 arrayvalues_pdfWoB.bin', dtype='<f8')
a = a.reshape((18, 7, 9, 6), order='C')

Python with Numpy (memmap):
---------------------------
import numpy as np
a = np.memmap('04 arrayvalues_pdfWoB.bin', dtype='<f8', shape=(18, 7, 9, 6), order='C')

R:
--
fileid <- file("04 arrayvalues_pdfWoB.bin", "rb")
a <- readBin(con=fileid, what=numeric(), n=6804, size=8, signed=TRUE, endian="little")
a <- array(data=a, dim=c(6, 9, 7, 18), dimnames=NULL)
close(fileid)

Matlab/Octave:
--------------
fileid = fopen('04 arrayvalues_pdfWoB.bin');
a = reshape(fread(fileid, 6804, '*float64', 'ieee-le'), [6, 9, 7, 18]);
fclose(fileid);

Julia (version < 1.0):
----------------------
fileid = open("04 arrayvalues_pdfWoB.bin","r");
a = map(ltoh, read(fileid, Float64, (6, 9, 7, 18)));
close(fileid);

Julia (version >= 1.0):
-----------------------
fileid = open("04 arrayvalues_pdfWoB.bin","r");
a = map(ltoh, read!(fileid, Array{Float64}(undef, 6, 9, 7, 18)));
close(fileid);

IDL/GDL:
--------
a = read_binary("04 arrayvalues_pdfWoB.bin", data_type=5, data_dims=[6, 9, 7, 18], endian="little")

Mathematica:
------------
a = BinaryReadList["04 arrayvalues_pdfWoB.bin", "Real64", ByteOrdering -> -1];
a = ArrayReshape[a, {18, 7, 9, 6}];

Maple:
------
a := FileTools[Binary][Read]("04 arrayvalues_pdfWoB.bin", float[8], byteorder=little, output=Array);
FileTools[Binary][Close]("04 arrayvalues_pdfWoB.bin");
a := ArrayTools[Reshape](a, [6, 9, 7, 18]);


Notes on dimensions and indexing of arrays
==========================================

The dimensions stated in the format description above are based on a row-major
memory layout where the *last* dimension is the one that varies most rapidly
with memory address. However, in some languages arrays are based on column-
major memory layout. To keep things efficient, the code examples above do not
change the memory layout when reading the array in a different language. This
means that in column-major languages, the dimension axes will be *reversed*.
Row-major languages are: Python and Mathematica. Columns-major languages are:
Julia, Matlab/Octave, R, Maple, and IDL/GDL.
